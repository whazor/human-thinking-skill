# human-thinking-skill

A Codex skill for guided reflection through simple, open questions.

Human Thinking asks one question at a time and leaves the thinking to you. Use it when you want guided reflection or explicitly invoke Human Thinking.

## Installation

Clone this repository into your Codex skills directory:

```sh
git clone git@github.com:whazor/human-thinking-skill.git ~/.codex/skills/human-thinking
```

The skill instructions are in [SKILL.md](SKILL.md).
